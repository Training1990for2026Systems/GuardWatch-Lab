# Security policy

GuardWatch-Lab is at the planning stage: this repository holds documents only, no code yet.

## Reporting a problem

Please report security problems **privately by e-mail** to **t90018273@gmail.com** (maintainer:
Training1990for2026Systems), not in a public issue. Include:

- which file of this repository it is about,
- what the problem is and how it shows.

You will get an answer by e-mail. Please give a reasonable time to fix the problem before talking about it publicly.

## Scope

- In scope: the files in this repository.
- Out of scope: Proxmox VE, Graylog, Windows and every other product named here. Report those to their makers.
